Open a YouTube watch page in a normal desktop window. Panes are resized by their borders and split, joined or reordered by dragging tabs; the numbers next to the YouTube logo switch workspaces. Local statistics are on by default: the welcome card shown above the recommended lists after installation describes them and has a "Turn stats off" button, and the Stats tab shows them. All data stays in the browser. To test the "Not interested" button, use a reviewer-controlled YouTube account: the button selects YouTube's own menu item, which YouTube offers only when signed in. On music.youtube.com only the tiling layout runs, and nothing is recorded there.

Source and build: the source ZIP is a git archive of the tagged commit, and its README.md has the build steps (Node.js 24 and pnpm: pnpm install --frozen-lockfile, then pnpm build --firefox writes dist-firefox/). The submitted files are esbuild bundles of the TypeScript in src/. There is no remote code.

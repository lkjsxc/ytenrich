Open a YouTube watch page in a normal desktop window. Panes are resized by their borders and split, joined or reordered by dragging tabs; the numbers next to the YouTube logo switch workspaces. Local statistics are on by default: the welcome card shown above the recommended lists after installation describes them and has a "Turn stats off" button, and the Stats tab shows them. The statistics database stays in the browser. To test the "Not interested" button, use a reviewer-controlled YouTube account: the button selects YouTube's own menu item, which YouTube offers only when signed in. On music.youtube.com the layout and separate local History/Stats run: each track start or replay counts after 10 seconds of playback. Music plays never feed YouTube recommendations.

Session playback: start a video, then use the YouTube logo, search box or a channel link to browse beside the same Player tile. Settings → Layout: Keep playing while browsing turns it off; closing Player stops playback. Saved watch layouts need a companion pane. The youtube.com-only MAIN-world bridge.js has four scoped operations: own-card navigation, restoring a loaded video’s watch page, native history traversal, and projected miniplayer sizing. It passes the selected video ID and optional playlist ID when an own-view card has no native matching link; synthetic watch-navigation DOM events alone proved insufficient. YouTube can also load a selected or next video directly in its miniplayer without changing pages. On native loadedmetadata/playing events, one coalesced frame reads only getVideoData().video_id while tiling and retained playback are active outside fullscreen. If it differs from the hidden watch page’s ID, the bridge clicks the native Expand control so that already-loaded video returns to its watch page and companions and the existing History/Stats record its ordinary open. It does not issue a second playback request. DOM links cannot identify this content reliably: the miniplayer shell has no content link and the player title has no content URL during an advertisement. Test selecting another video from the browsed channel. For Back/Forward from a loaded watch player, cached traversal can reset media without normal navigation, so the bridge can route YouTube’s current history endpoint instead. This path reads the current history.state.endpoint and requires a trusted browser popstate, tiling/session readiness, loaded media, a non-watch/non-Shorts destination outside fullscreen, and the endpoint URL matching the browser’s already-selected URL. It suppresses the original popstate only after synchronous native navigate-start acknowledgement; own-card requests still carry validated watch URLs, not arbitrary endpoint commands. Test Back to watch followed by Forward to the browsed page. The sizing operation accepts a ytenrich-player-resize signal with no payload, reads the active projected miniplayer slot’s actual rectangle, and calls the existing player’s setInternalSize with rounded dimensions when available. It is requested by the existing 120ms projection resize batch. One observer watches only the current video’s style writes and tiling shutdown, compares native dimensions with the tile, and corrects changed measurements without polling or a feedback loop: CSS/window resize alone left native seek/chapter controls at 400px in a 947px tile. It does not clone, seek or reload media; if the method is unavailable, CSS still fits the video. Test resizing the player pane and its seek/chapter track. The bridge does not call extension APIs, read extension storage, store history entries or dimensions, make direct network requests, add telemetry or load remote code; YouTube handles the resulting navigation requests. Host permissions and locally recorded fields are unchanged.

Source and build: the source ZIP is a git archive of the tagged commit, and its README.md has the build steps (Node.js 24 and pnpm: pnpm install --frozen-lockfile, then pnpm build --firefox writes dist-firefox/). The submitted files are esbuild bundles of the TypeScript in src/. There is no remote code.
